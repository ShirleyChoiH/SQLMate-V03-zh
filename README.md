# SQLMate-V03-zh
## 适用场景
- 需要编写 SQL 查询来检索数据，但不确定如何编写或从何入手时。
- 不确定获取结果所需的基础数据逻辑时。

## 为什么要用？
- 优化的 SQL 输出：生成高效、运行时间最短的 SQL 查询，您可直接使用。
- 详细解释：逐行拆解查询语句，让您清楚了解每条语句的作用。
- 重要提示：提醒你潜在的数据注意事项和边界情况（例如，提示你不同网页页面的用户总数可能存在重叠）。
- 迷你课堂：最后附上所用关键 SQL 函数和概念的简短说明（含图解）。

## 适合人群……
- SQL 学习者和学生。
- 需要在工作或学习中经常使用 SQL 的职场人士和学生。

## 如何安装
- 下载本文件。
- 将其安装到AI 智能体中。

## 使用方法
- 将数据库信息（字段/列名、数据库介绍或表结构）上传至 AI 智能体或直接告诉AI
- 用通俗语言描述您想要获取的数据或统计指标。
